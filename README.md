# エスピクトスクール — 「すっげ〜」版ランディングページ

`../service-page/` の内容（文言・注記・承認済み画像）をそのまま使い、見せ方とインタラクションを作り直したページです。
ビルド不要の静的サイトです（HTML / CSS / JavaScript のみ、外部ライブラリなし）。

## 見かた

- `index.html` をブラウザで直接開けば表示できます。
- ローカルサーバーで見る場合: `python3 -m http.server 8000`（このフォルダで実行）→ http://localhost:8000/

## 主な仕掛け

| セクション | 内容 |
| --- | --- |
| ヒーロー | カーソルに反応するピクセルの波（canvas）、見出しの一文字ずつの登場、ブランドポスターの斜めスラブ、じゃっぷちゃんと浮遊UIのパララックス。じゃっぷちゃんを押すとセリフが変わります |
| 帯 | 仕事のジャンルと「学ぶ・聞く・つくる・確かめる・届ける」が流れる2本の斜めマーキー |
| ABOUT | 「教材・授業・AI ＋ 実際の仕事 ＝ できる」の式カード |
| 動画 | 36秒の紹介動画（クリックで再生） |
| 活用イメージ | 3つのモデルケースをタブで切り替え（矢印キー対応） |
| アプリ | スクロールに合わせて右の画面がピクセル状に切り替わるスティッキー表示。実画面は「実画面を確認」ボタンからダイアログで表示 |
| 取り組める仕事 | PCでは縦スクロールで横に流れるギャラリー、スマホではスワイプのカルーセル |
| 役割 | 役割A/B/Cを選ぶと制作ボードが組み上がり、3つそろうと「完成！」 |
| 仕組み | 事業所・エスピクト・企業の流れを動く点線で表示、案件の金額帯をカウントアップ |
| 進め方 / 導入の流れ | スクロールで進むパイプライン、じゃっぷちゃんのアイコンが道筋をたどる4ステージ |
| フッター | カーソルに反応する ESPICT SCHOOL の大きなロゴ文字 |

## アクセシビリティ

- 左下の ⏸ ボタンですべての動きを止められます（設定はブラウザに保存）。OSの「視差効果を減らす」設定にも従います。
- キーボード操作（スキップリンク、タブ、ダイアログ、メニュー）とスクリーンリーダー向けのラベルに対応しています。
- 生成イラストや構想画面には、元ページと同じ注記を付けています。

## 素材と文言

- 文言・注記（「モデルケースであり実績ではない」「金額は案件額であり工賃ではない」など）は元ページのまま使っています。新しい主張や数字は加えていません。
- 画像は `service-page/assets/SOURCES.md` で現在使用中とされているものだけをコピーしました（`app-real/` など不採用の素材は使っていません）。
- 問い合わせ・LINE・運営会社などのリンクは元ページと同じ本番URLです。

## フォント

- Noto Sans JP / DM Sans: 元サイトと同じサブセット（`css/fonts.css`）
- Dela Gothic One（見出し）/ Yomogi（手書き風のひとこと）: SIL Open Font License 1.1。ページで使う文字だけのサブセットです
  - Dela Gothic One は `css/style.css` にデータURLとして埋め込んでいます（`file://` で開いても読み込めるように）
  - 見出しに新しい漢字を足すと、その文字だけ Noto Sans JP で表示されます。Google Fonts の `text=` パラメータでサブセットを取り直せば揃います
